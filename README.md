# Rule-Based Python Chatbot 🤖

A lightweight, rule-based chatbot written in Python. This mini-project demonstrates object-oriented programming (OOP) principles, time-aware control flow logic, and simulated conversational latency. 

## 🚀 Features
* **Time-Aware Greetings:** Dynamically greets the user based on the current system time.
* **Keyword Matching:** Scans user input to provide predefined, contextual responses.
* **Simulated Processing:** Utilizes the `time` module to create a natural conversational flow.
* **Modular Design:** Built using a Python class for easy expansion and reusability.

## 🛠️ How to Run
1. Ensure you have Python installed on your system.
2. Clone this repository or download the `chatbot.py` file.
3. Open your terminal or command prompt.
4. Run the script using the following command:
   ```bash
   python chatbot.py
